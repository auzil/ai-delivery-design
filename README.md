# PCX Kurýr — landing page prototype (variant a-close)

Static HTML design prototype for a weekly/monthly Honda PCX 125 rental for delivery couriers in Prague. Open `index.html` in a browser, or view it on GitHub Pages.

**This is a design preview, not a live business page.**

- Brand name, prices (1 490 Kč a week, 4 990 Kč a month), included items, replacement terms, start time, reply times, calculator defaults, fuel consumption and FAQ answers are sample values awaiting the owner's confirmation.
- Contact links point to the on-page application form; the phone number shown is a dummy.
- The application form doesn't send anything; it only shows its success state.
- All photos are AI-generated placeholders (Gemini) and show no real people, vehicles or locations of the business. They will be replaced by a real photo shoot.
- Honda and PCX are trademarks of Honda Motor Co., Ltd.; the page is not affiliated with Honda.

## Structure

```
index.html   the whole page: inline CSS and JS, fonts from Google Fonts, GSAP from jsDelivr
assets/      scratch texture and two cropped photos
images/      temporary AI-generated photos
```
